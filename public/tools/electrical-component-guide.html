先分清三套名称：设备标识符是工程中的设备名字；符号名称是符号库检索名；产品型号是厂家产品规格。它们不能互相替代。

用一只接触器来理解

=MOTOR+CP1-KM1：在这个工程中表示某个功能、位置下的一只接触器。结构段含义以项目配置为准。

KM1：本工具采用的常见习惯代号；其他企业或标准体系可能用 K、Q 等。

NXC…：厂家产品系列/型号；线圈电压、触点配置等还要完整指定。

一个物理接触器可以在图中分成线圈、主触点、辅助触点。相同设备归属和交叉引用把它们关联起来。

在 EPLAN 里找器件的顺序

  1. 确定用途：保护、开关、测量还是执行？
  2. 选择正确符号库与表达类型：单线、多线等。
  3. 看中文描述、预览图和功能定义，不猜英文名称。
  4. 确认连接点数量、方向及常开/常闭特征。
  5. 按产品样本填写端子，之后关联真实部件。

找不到合适的复杂器件时，可用黑盒与设备连接点表达；端子标识必须与手册核对。

常见端子如何读

常见标记经常表示需要核对
A1 / A2接触器或继电器线圈线圈电压、AC/DC及极性，不能凭端子号推断电压。
13–14 / 21–22常开 / 常闭辅助触点的常见编号实际触点块可能用11–12等；看厂家图。
11 / 12 / 14一组转换触点常见为公共 / 常闭 / 常开插座脚号与端子功能号不一定相同。
95–96 / 97–98热过载继电器常闭 / 常开辅助触点确认与具体器件一致。
1L1、3L2、5L3 / 2T1、4T2、6T3三极接触器等的主回路端子进出方向与器件适用接线看样本。
R/S/T / U/V/W变频器常见电源输入 / 电机输出不得把电源接到输出端；系列端子可能不同。
DI / DO / AI / AO数字输入 / 数字输出 / 模拟输入 / 模拟输出相对当前设备定义；电压、电流、公共端需匹配。
PE / N / 0V / COM / GND保护接地 / 中性导体 / 直流参考 / 公共端 / 地参考不是同义词，不因名字像就短接；由接地与隔离方案决定。

触点的“正常状态”

普通触点图形通常按未操作、线圈未励磁等参考状态表示。常开 NO 在该状态断开，常闭 NC 在该状态闭合。传感器的 NO/NC 则按其检测状态定义核对。

NO/NC 描述通断逻辑；PNP/NPN 描述电子输出结构；瞬时/保持描述操作方式。这是三个不同维度。

图纸检查与真实设备

图形画对不等于功能定义对；检查无错误不等于选型、载流量或安全功能已经验证。

主功能用于同一设备的数据管理，不是“哪一根线重要”。同一设备不同表达的设置应按工程与 EPLAN 功能要求处理，不能给每个辅助触点都勾主功能。

怎么用这份网页

这是学习识别工具，不给出一套可以照搬的最终选型。代号采用国内工程中常见的习惯写法，企业规则、采用的标准和 EPLAN 分类体系可能不同。简图用于识别原理，未声称符合某一符号标准的精确绘制要求。

本文件的内容、图形、搜索和自测都可离线使用；点击外部资料链接时需要联网。未嵌入或伪造产品实物照片；外形与真实端子请打开官方样本对照。

适用重点是低压配电与工业自动化；电子器件和中压设备只作常见概念识别，不覆盖所有专业的全部器件。
