## 项目定位

C2项目开始进入正式联调阶段。本项目使用TIA Portal V19完成S7-1500控制程序，以GRAPH组织灌装顺序，以LAD完成模式、报警、计数和最终输出控制，再通过S7-PLCSIM Advanced V6.0与Factory I/O搭建虚拟生产线。

今天完成的重点不是单独验证某一个线圈，而是把PLC程序、虚拟PLC实例、Factory I/O驱动和场景中的执行器连接成一条完整链路。

> 本文记录当前阶段的真实进度。HMI画面和整线动态测试尚未完成，因此项目仍处于进行中状态。

## 二、PLC程序架构

OB1中的程序按照以下顺序调用：

| 顺序 | 程序块 | 主要职责 |
|---:|---|---|
| 1 | `FB_Alarm` | 汇总急停、传感器和过程故障 |
| 2 | `FB_ModeControl` | 处理启停、复位、自动模式和系统允许 |
| 3 | `FB_FillingSequence` | 使用GRAPH执行自动灌装步骤 |
| 4 | `FB_Counter` | 完成成品计数及计数复位 |
| 5 | `FC_OutputControl` | 统一生成输送机、灌装阀和指示灯等物理输出 |

这样的调用顺序保证报警与模式状态先被计算，GRAPH随后根据最新的系统允许条件运行，最终输出则在周期末统一生成。

## 三、GRAPH灌装流程

当前自动流程划分为七个步骤：

| 步骤 | 名称 | 动作说明 |
|---|---|---|
| S0 | 待机 | 等待系统允许和自动运行条件 |
| S10 | 进瓶 | 启动输送及工件发射，使瓶体进入产线 |
| S20 | 稳定 | 到位后短暂停留，避免立即灌装造成过程抖动 |
| S30 | 灌装 | 打开灌装阀并保持设定时间 |
| S40 | 滴漏等待 | 关闭灌装阀后等待残液滴落 |
| S50 | 出瓶 | 重新启动输送机，将成品送往出口 |
| S60 | 完成 | 完成一次循环并返回待机步骤 |

### 故障时不仅关输出，也要停止顺控

调试过程中发现一个需要保留的重要安全逻辑：如果只在最终输出层加入报警联锁，发生报警后实际Q点会安全关闭，但GRAPH仍可能继续根据转换条件跳步。故障解除时，顺控器可能已经不在预期步骤。

因此增加了顺控关闭命令：

```text
xSequenceOffCmd = NOT xSystemEnableSts
```

并将其连接到GRAPH的`OFF_SQ`输入。这样系统失去允许条件或发生报警时，物理输出与顺控流程都会停止，避免“设备停了但步骤仍在后台运行”。

## 四、I/O分配

### PLC输入

| 地址 | 信号 | 作用 |
|---|---|---|
| I0.0 | 启动按钮 | 启动系统 |
| I0.1 | 停止按钮 | 停止系统 |
| I0.2 | 故障复位 | 复位报警 |
| I0.3 | 急停正常 | 急停回路允许状态 |
| I0.4 | 自动模式 | 选择自动运行 |
| I0.5 | 灌装位传感器 | 检测瓶体到达灌装位置 |
| I0.6 | 出口传感器 | 检测瓶体离开及计数 |
| I0.7 | 计数复位 | 清零成品计数 |

### PLC输出

| 地址 | 信号 | Factory I/O对象 |
|---|---|---|
| Q0.0 | 输送机运行 | Belt Conveyor |
| Q0.1 | 灌装阀 | 灌装动作/指示 |
| Q0.2 | 运行灯 | Light Indicator |
| Q0.3 | 故障灯 | Light Indicator |
| Q0.4 | 工件发射 | Emitter |
| Q0.5 | 工件移除 | Remover |

Factory I/O驱动中的布尔输入、布尔输出起始偏移均设置为0，数量设置为16。今天已完成上述信号映射，并清除了映射界面的错误、强制和故障提示。

## 五、Factory I/O场景

场景坚持从空白开始自行搭建，目前部署的主要部件如下：

| 中文名称 | Factory I/O英文名称 | 数量 |
|---|---|---:|
| 工件发射器 | Emitter | 1 |
| 皮带输送机 | Belt Conveyor（6 m） | 1 |
| 漫反射传感器 | Diffuse Sensor | 2 |
| 工件移除器 | Remover | 1 |
| 灯柱/立柱电柜 | Pole / Electrical Cabinet | 1 |
| 指示灯 | Light Indicator | 3 |

两个漫反射传感器分别用于灌装位检测和出口检测；立柱电柜用于放置运行、灌装和故障指示灯。Emitter与Remover已加入PLC输出控制，工件类型采用`Box (S)`，以便先完成输送和检测逻辑的联调。
