## 先分对象：谁的额定电流？

“电机的额定电流”是“额定电流”在电机上的具体应用。但**电机额定电流、断路器额定电流、接触器额定工作电流，不是同一个参数**。讨论时先明确设备对象。

| 对象 | 电流说明什么 | 还要核对什么 |
| --- | --- | --- |
| 电机 | 规定额定条件下的电流基准 | 电压、频率、接法、输出与工作制 |
| 断路器 | 器件的额定参数 | 脱扣器、整定范围、环境及保护配合 |
| 接触器 | 指定使用类别与电压下的工作能力 | AC-3 等类别、操作条件 |
| 导线 | 给定条件下的允许载流量 | 截面、材料、温度、成束及敷设方式 |

下文用 $I_N$ 专指**电机额定线电流**，避免与断路器额定值混淆。

## 看铭牌：额定电流是规定条件下的基准

额定电流不是所有状态下都不能瞬间超过的“绝对上限”。启动时可以短时高于额定值。[ABB 的铭牌说明](https://new.abb.com/news/detail/132261/how-to-read-a-nema-motor-nameplate)将满载电流与额定负载、额定电压联系起来。

同一台电机可以列出多组额定条件，不能只挑其中一个电流数字。

| 铭牌字段 | 识读重点 |
| --- | --- |
| 功率 kW | 通常是轴端机械输出，不是输入电功率 |
| 电压、接法、电流 | 按同一组额定条件对应读取 |
| 频率、工作制 | 核对供电与连续、短时等运行条件 |
| 效率、功率因数 | 对应工作点参数，不混用其他型号数据 |
| 防护、绝缘等级 | 核查环境和热条件，不能替代温升校核 |

## 看仪表：工作电流是当时的实际值

工作电流 $I$ 是实际运行时流过导体的电流，受负载、电压、三相不平衡、控制方式等影响。**铭牌提供基准，测量反映现场状态。**

普通电流钳测单根导体电流时，需按仪表说明确定测量位置与量程；往返导体一起钳入时，测量含义会改变。启动暂态需要相应的浪涌捕获功能，普通刷新读数不一定能捕捉。参阅 [Fluke 钳表读数说明](https://www.fluke.com/en/learn/blog/clamps/clamp-meter-readings-problems-and-solutions)。

<div><span>假设铭牌为 15.8 A</span><strong>实测 18 A</strong><p>高于额定值，应先区分启动暂态与持续运行，再核查三相电流、电压、负载和温升。</p></div>

空载也存在励磁电流，电流不与机械负载严格成正比。“空载一定为额定的 30%～50%”不是通用判据。保护是否动作还取决于超出程度、持续时间、热状态与动作曲线，不能从一次 18 A 读数推出“立即跳闸”。

## 六种电流，一张表分清

| 名称 | 本文记号 | 核心含义 | 用途 |
| --- | --- | --- | --- |
| 额定电流 | $I_N$ | 电机规定额定条件下的电流基准 | 核对电机与保护方案 |
| 工作电流 | $I$ | 当前工况实际流过的电流 | 监测与故障分析 |
| 启动电流 | $I_{st}$ | 启动阶段随过程变化的电流 | 启动、压降与保护配合校核 |
| 计算电流 | $I_B$ | 按设计负荷及使用条件确定的电流 | 回路与导线、开关设计 |
| 整定电流 | $I_r$ | 保护装置设定的电流参数 | 与延时、曲线共同确定保护特性 |
| 预期短路电流 | $I_k$ | 指定故障点在给定电源和阻抗下的预期电流 | 分断能力、耐受与保护配合校核 |

记号是本文约定；其他资料或设备可能用 FLA 等标注，先看定义。

## 从电流到选型，还差哪些条件？

### 启动：不能固定套“6～7 倍”

直接启动异步电机常出现数倍额定电流，但倍数与时间取决于电机、负载和启动方式。星三角、软启动、变频启动的特征也不同。启动校核不仅涉及瞬时脱扣，还涉及启动时间、过载保护曲线、接触器使用条件和电源压降。

### 整定：不能统一乘 1.0～1.1

先明确**保护装置检测的是线电流还是绕组支路电流**，再按产品说明、接线与保护配合确定整定。既不能把某次轻载实测值直接当设定值，也不能只靠一个倍率包办。

例如，星三角启动器中，某些过载继电器安装在三角形绕组支路内，检测电流约为线电流的 $1/\sqrt{3}$，即约 0.58 倍。这是特定接法的结果，不能推广到全部安装位置。[施耐德官方说明](https://www.se.com/ca/en/faqs/FA111375/)给出了这一情形。

### 选型：额定电流是起点

| 设计动作 | 还需核对的条件 |
| --- | --- |
| 选择断路器 | 启动与脱扣特性、短路分断能力、上下级及过载保护配合 |
| 选择接触器 | 电压、AC-3 等使用类别、操作频次、环境修正 |
| 选择导线 | 敷设修正后的载流量、压降、短路热稳定及保护配合 |
| 整定过载保护 | 额定数据、接线位置、脱扣级别、启动时间与厂家要求 |
| 判断异常运行 | 三相电流和电压、持续时间、机械负载、温升、测量条件 |

“选型一律只看额定电流”应改为：**以额定数据为重要依据，结合设计负荷、启动工况、安装条件与保护配合完成校核。**

## 计算值为什么和铭牌不同？

三相平衡，并采用对应工作点参数时：

$$
I=\frac{P_2}{\sqrt{3}\,U_L\,\eta\,\cos\varphi}
$$

轴端输出 7.5 kW、线电压 380 V、效率 0.88、功率因数 0.82，得到约 **15.79 A**。若效率和功率因数是假设值，结果就是这些假设下的估算；不是所有计算都天然“不准确”。

铭牌是具体型号在额定条件下的重要设计依据，也不是任意工况下的实时测量值。正式设计还须核对厂家资料、应用条件与适用要求。已有实物时先读清对应铭牌，避免混用其他型号参数。完整计算见 [A2｜单台电机额定电流](/posts/a2-motor-rated-current/)。

## 两道自测题

<div class="a2-exercise">
<p><strong>① 铭牌 15.8 A，实测 12 A 或 18 A，能直接判断什么？</strong></p>
<details><summary>展开答案</summary><p>先确认测点电流与额定值的大小关系，再核对工况、三相状态和持续时间。不能直接换算机械负载率，也不能把一次高读数等同于确定的持续过载或必然立即跳闸。</p></details>
<p><strong>② 为什么热继电器不能都设成额定电流的 1.1 倍？</strong></p>
<details><summary>展开答案</summary><p>接线位置可能改变被检测电流，产品和启动工况也不同。应按具体装置说明与保护配合确定，不能绕过这些条件套倍率。</p></details>
