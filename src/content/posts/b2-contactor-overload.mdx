## 接触器：电流前面还有使用类别

接触器不只是长期通流，还要接通和分断负载。同一产品在不同负载和操作条件下，额定工作电流可能不同。

| 类别 | 典型工况 | 选型时理解什么 |
| --- | --- | --- |
| AC-1 | 无感或微感负载，例如电阻加热 | 不能将该额定值直接当成电机开关容量 |
| AC-2 | 绕线转子电动机启动与分断 | 与本篇鼠笼电机工况区分 |
| AC-3 | 鼠笼电机启动，运行中分断 | 启动时接通较大电流，正常运行时分断 |
| AC-3e | 较高堵转电流的鼠笼电机工况 | 按电机特性和厂家相应额定表核对 |
| AC-4 | 点动、反接制动等严酷操作 | 分断时也可能遇到很大的电流，不能直接沿用 AC-3 容量 |

定义可核对 [施耐德接触器使用类别说明](https://productinfo.se.com/tesysgigainstallationguide/tesys-giga-series-giga-contactors-and-giga-thermal-overload-relays-installation-guide/English/TeSys%E2%84%A2%20Giga%20Series%20Giga%20Contactors%20and%20Giga%20Thermal%20Overload%20Relays%20Installation%20Guide_0000447511.xml/%24/PanGu_LoadsCPT_0000507717)。照明并不一概属于 AC-1；白炽灯、放电灯及其他光源有不同冲击和分类条件。

“AC-3 接通数倍额定电流、运行时分断”的描述用于理解开关负担，不意味着所有电机启动电流固定为 6 倍，也不能把一个倍数当作完整的试验条件。正反转是否属于严酷工况，要看换向时电机状态和操作方式，不能只看回路名称。

### 同一产品，为什么能同时标 18 A 和 32 A？

[Schneider Electric 旗下 Clipsal 的 LC1D18BD 参数页](https://www.clipsal.com/products/industrial/tesys/contactor-3p3no-ac-3-ac-3e-440v-18a-24v-dc-coil-lc1d18bd?itemno=LC1D18BD)列出：在相应温度、工作电压条件下，AC-3 为 **18 A**，AC-1 为 **32 A**，线圈为 **24 V DC**。这几个额定值分别描述不同用途，不能互相替代。

本题 18 ÷ 15.8 ≈ **1.139**，可将 18 A 规格作为候选。但“所有接触器必须乘 1.1～1.25”不是通用选型规则。还需按实际电压、使用类别、操作频次、寿命、温度修正及厂家协调表核对。若项目确实要求不小于 1.25 倍，则 18 A 又达不到 19.75 A，不能一边声称满足全部倍率、一边直接定 18 A。

## 线圈：24 V DC 不等于必然能直连 PLC

主触点的 18 A 与线圈需要的驱动电流不是一回事。线圈应匹配控制电源的电压、交直流类型及允许波动范围。

| 核查项 | 原因 |
| --- | --- |
| 吸合和保持功耗 | PLC 输出需同时满足瞬态与持续负载能力 |
| 输出类型、极性及公共端 | 晶体管、继电器输出的接法和限制不同 |
| 感性负载抑制与关断时间 | 保护输出，同时核查释放速度是否满足控制要求 |
| 通道及整组电流限制 | 单点合格不代表整组同时动作也合格 |
| 辅助触点 | 自锁、互锁、反馈所需数量及触点使用类别要匹配 |

满足厂商接口条件时可以直接驱动；不满足时选合适的接口或中间继电器。不能从“DC24V”四个字推出“不需要中间继电器”。厂家也将类别、负载额定、线圈和触点配置分别列入 [接触器选择要素](https://www.se.com/id/en/faqs/FA349691/)。

普通辅助触点反馈也不自动等同于安全反馈，正反转的机械与电气互锁应按具体方案实现。

## 热继电器：先选范围，再确定整定值

**范围是能调到哪里，整定值是实际设在哪里。** 还要明确电流检测位置：本节按装在线电流路径中讨论，不能直接推广到星三角绕组支路内。

| 题目给定范围 | 对本题约 15.8 A 基准的判断 |
| --- | --- |
| 10～14 A | 不能覆盖该目标值 |
| 14～20 A | 覆盖，作为题目中的合适量程 |
| 20～25 A | 下限已高于基准，不适合作为本题贴近铭牌整定的量程 |

20～25 A 档并非“任何过载都永远不动作”，而是在需要保护的较低过载区可能过迟动作，无法据此建立合适的电机保护。

### 整定：贴近铭牌，不是统一加 10%

[施耐德对 LR*D* 刻度的说明](https://www.se.com/us/en/faqs/FAQ000278064/)指出，刻度代表电机额定电流或满载电流，设置还受产品说明和安装地适用要求影响。该资料中的北美规则示例不能直接搬成所有项目的通用倍率。

在本题线电流检测、按电机铭牌电流设置的假设下，以 **15.8 A** 为基准。若实际刻度和说明允许，可设置到相应位置；“约 16 A”是识读示例，不是强制把所有 15.8 A 都向上取整。不能以电压波动、温度或“防误动”为由统一乘 1.1。

整定刻度也不是超过后立即动作的硬门槛。18 ÷ 15.8 ≈ **1.139**，说明设置比该电机基准高约 13.9%；这会改变保护配合，但不能直接推导为“114% 电流下一定永不动作”。动作还取决于时间、冷热状态、缺相条件及装置曲线。

### 端点：不是天然的禁用区

假设目标整定值为 16 A，14～20 A 量程中的位置为 (16−14) ÷ (20−14) ≈ **33.3%**。这个算式能说明刻度位置，不能证明“只有 1/3～2/3 才合格”。

如果某真实产品允许在 16～20 A 范围内设置 16 A，**不能仅因落在下限就判定不可用**。应核对产品允许范围、精度和应用条件；没有依据说所有热继电器在两端精度都最差。

## 脱扣等级、缺相与复位

脱扣等级要匹配启动过程与电机热承受能力。“Class 10”与“Class 10A”是不同标记，后者的 A 不是“安培”。厂家产品表中的等级必须原样核对，不能把照片中的 LRD21 写成 Class 10。

| 需要检查 | 重点 |
| --- | --- |
| 脱扣等级 | 按规定试验电流、冷热状态和完整曲线理解，不等同于任何过载固定几秒跳闸 |
| 启动过程 | 普通或长时间启动均需与动作曲线比较，不能仅按负载名称选等级 |
| 缺相敏感性 | 核对具体产品能力与接线，不认为任意缺相故障均能完全覆盖 |
| 手动复位 | 排查故障后人工恢复，但复位本身不应造成意外启动 |
| 自动复位 | 与控制逻辑共同评估，持续启动命令可能造成再次吸合 |

热继电器通常借助辅助触点使接触器释放，**并不靠自身切断主回路短路电流**。常见 95–96 常闭触点用于切断控制回路，97–98 常开触点用于故障信号，仍应按目标型号的端子图确认。

## 两轮作答：哪些保留，哪些要修正？

| 作答与原批改 | 复核后的结论 |
| --- | --- |
| 接触器至少 16 A，原批改要求 18 A | 题目严格电流下限为 15.8 A；16 A 不能仅凭“没乘 1.1”判错。18 A 是可进一步校核的产品规格 |
| 不按 AC-1 数值选电机接触器 | 方向正确，应核对实际操作类别、工作电压和相应额定值 |
| 选 14～20 A，设 18 A | 量程覆盖目标；18 A 比 15.8 A 高约 13.9%，缺少采用该设定的依据 |
| 20～25 A 档保护不合适 | 方向正确，但不是任何过载下都绝不动作 |
| 补答选 16～20 A，设 16 A | 不在原题给定选项内；但“16 A 处于真实允许量程下限”本身不构成禁用理由 |
| 热继决定电机烧不烧 | 过度简化；还取决于故障类型、保护接线、整定配合、电机热状态等 |

## 一条回路，三个元件配合

| 元件 | 在本篇常见组合中的职责 | 不能由名称推断的事 |
| --- | --- | --- |
| QF 断路器 | 短路保护，是否兼顾过载取决于装置及配合；隔离功能须核对 | 不直接沿用“16 A / D / 6 kA”作为已定结论 |
| KM 接触器 | 日常接通、分断电机回路 | 不单独提供完整的过载或短路保护 |
| FR 热继电器 | 检测过载，并通过控制回路触发停机 | 不代替短路保护，也不保证覆盖全部电机故障 |

不能用“断路器寿命只有数千次”概括所有产品；是否允许用于操作及其频次，应看具体额定用途和寿命数据。

## 自测：范围覆盖了，能否直接定型？

<div class="a2-exercise">
<details><summary>展开答案</summary><p>不能。电流覆盖只完成一项检查，还要核对使用类别与电压、温度和频次、线圈驱动、安装兼容、脱扣等级、接线位置以及短路和过载保护配合。量程端点不是天然禁用区，统一加10%也不是通用整定规则。</p></details>
