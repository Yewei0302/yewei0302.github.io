# 叶工的自动化学习笔记

这是我的个人技术博客，用于记录PLC、电气工程、自动化控制和项目实践过程中的学习、调试与复盘。

## 🌐 在线访问

[https://yewei0302.github.io/](https://yewei0302.github.io/)

## 📚 主要内容

- 西门子S7-1200与S7-1500 PLC
- TIA Portal与LAD梯形图编程
- PLCSIM虚拟调试
- 模拟量采集与工程量转换
- PID闭环控制
- WinCC与HMI画面
- 电气故障分析与项目复盘
- 自动化系统学习记录
