## 同步GitHub

用户说“同步GitHub”时，先备份工程外的本地内容与远程历史，fetch 后比较双方文章、草稿、隐藏状态和资源。远程其他设备的新提交须保留双方后合并，不用 pull/reset/checkout 覆盖未提交修改。不按时间简单选版本；不确定原件保存在工程外并说明。

审查 .gitignore、密钥与大文件；不提交依赖、构建、缓存、日志、备份或凭据，保留有效源码、文章、静态资源、配置及锁文件。必要私密配置改用环境变量。运行实际构建与资源/样式检查，检查暂存差异无内容丢失后普通提交并推送默认分支；禁止 force push 和删除远程分支。

GitHub 同步不是网站发布。deploy.yml 已改为无部署能力的手动说明流程；其他检查工作流保留。不要启用会将旧源码部署到同站点的工作流。
